🎮 1. องค์ประกอบของ RL

เรียนแบบ ลองผิดลองถูก: agent ทำ action → environment ส่ง reward + state ใหม่ กลับมา เป้าหมาย = return ระยะยาวสูงสุด (ไม่ใช่ reward ก้าวเดียว)

sₜ → [Agent π] → aₜ → [Environment] → rₜ₊₁, sₜ₊₁ → …
State sสถานการณ์ที่ agent เห็น (ตำแหน่งในตาราง, ภาพหน้าจอ)
Action aทางเลือก (ขึ้น/ขวา/ลง/ซ้าย, ดันซ้าย/ขวา)
Reward rตัวเลขบอกว่าดีแค่ไหน ไม่บอกว่าควรทำอะไร
Policy πกฎเลือก action จาก state, π* = argmaxₐ Q*(s,a)
Episodeเล่น 1 รอบ: terminated = จบตามกฎ, truncated = หมดเวลา
SupervisedRL
สัญญาณสอนlabel ที่ถูกต้องreward (มาช้า, credit assignment)
ข้อมูลi.i.d.ต่อเนื่อง, action มีผลต่ออนาคต
💰 2. Return · MDP · Bellman
Gₜ = rₜ₊₁ + γ rₜ₊₂ + γ² rₜ₊₃ + … = Σₖ γᵏ rₜ₊ₖ₊₁

ตัวอย่าง: −0.04 × 5 ก้าว แล้ว +1, γ = 0.9 → G₀ = −0.04(1+0.9+0.81+0.729+0.6561) + 0.9⁵ = 0.4267

  • γ = 0 สายตาสั้น (สนแค่ r ถัดไป) · γ → 1 มองไกล
  • ขอบเขตมองไกล ≈ 1/(1−γ): γ = 0.99 → 100 (Q ของ CartPole เก่ง ๆ ≈ 90–100)

MDP = (S, A, T(s,a,s'), R, γ) · Markov: P(sₜ₊₁ | sₜ, aₜ) ไม่ขึ้นกับอดีต (ภาพเดียวของ Atari ไม่ Markov → ซ้อน 4 เฟรม)

Vπ(s)E[Gₜ | sₜ = s] — state นี้ดีแค่ไหน
Qπ(s,a)E[Gₜ | sₜ = s, aₜ = a] — ทำ a ใน s ดีแค่ไหน · V*(s) = maxₐ Q*(s,a)
Q*(s,a) = Σₛ' T(s,a,s') [ R(s,a,s') + γ maxₐ' Q*(s',a') ]

รู้ T, R → Value Iteration (DP) · ไม่รู้กฎ → เรียนจากประสบการณ์ (Q-Learning, model-free)

🧮 3. Q-Learning Update
Q(s,a) ← Q(s,a) + α [ r + γ maxₐ' Q(s',a') − Q(s,a) ]

ในวงเล็บ = TD error δ · ถ้า s' เป็น terminal → TD target = r เท่านั้น

ตัวอย่าง Q = 0.5, r = −0.04, Q(s',·) = [0.2, 0.8, 0.6, 0.1], α = 0.1, γ = 0.9

  1. TD target = −0.04 + 0.9 × 0.8 = 0.68
  2. δ = 0.68 − 0.5 = 0.18 → Q ใหม่ = 0.5 + 0.1 × 0.18 = 0.518
พารามิเตอร์บทบาทค่าที่นิยม
α learning rateขยับ Q แรงแค่ไหน (มาก=แกว่ง, น้อย=ช้า)0.05–0.5
γ discountให้น้ำหนักอนาคต0.9–0.99
ε explorationโอกาสสุ่ม action1.0 → 0.01–0.1

Q-Learning = off-policy (เดินสุ่มก็เรียน policy ดีที่สุดได้) · SARSA = on-policy ใช้ Q(s',a') ของ action ที่ทำจริง

🎲 4. Exploration vs Exploitation · ε-greedy
def epsilon_greedy(q_row, eps, rng): if rng.random() < eps: # explore return int(rng.integers(len(q_row))) best = np.flatnonzero(q_row == q_row.max()) # exploit return int(rng.choice(best)) # สุ่มเมื่อเสมอ eps = max(eps_min, eps * 0.995) # decay ทุก episode

P(เลือก action ดีที่สุด) = (1 − ε) + ε/|A| เช่น ε = 0.2, 4 actions → 0.85 · 0.99¹⁰⁰ ≈ 0.366

S . . . . # . T . . . . T . # G

Policy ที่เรียนได้ (500 episodes)

→ → ↓ ← ↓ # ↓ T → → → ↓ T ↑ # G
  • ทางสั้นสุด 6 ก้าว, reward รวม 0.80 · V(start) = 0.427 = G₀ ที่คำนวณมือ (ข้อ 2)
  • Q(state 6, →) = −0.948 → เรียนรู้ว่าเดินขวาคือตกกับดัก · state ที่ไม่ค่อยถูกเยี่ยม ค่า Q ยังไม่ลู่เข้า
s, info = env.reset(); done = False while not done: a = epsilon_greedy(Q[s], eps, rng) s2, r, terminated, truncated, info = env.step(a) target = r if terminated else r + gamma * Q[s2].max() Q[s, a] += alpha * (target - Q[s, a]) s, done = s2, terminated or truncated

Gymnasium: reset() คืน (obs, info), step() คืน 5 ค่า · FrozenLake-v1: 0=ซ้าย 1=ลง 2=ขวา 3=ขึ้น, ลื่นไปทิศที่ตั้งใจ 1/3

🏆 6. Reward Design
แบบข้อดีข้อเสีย
Sparse (+1 ที่เป้าหมายเท่านั้น)นิยามง่าย ไม่ชี้นำผิดเรียนช้า อาจไม่เคยเจอ reward
Shaped (โบนัสระหว่างทาง)เรียนเร็วเสี่ยง reward hacking
  • step +0.2 → เดินวนไม่จบ (0.2/(1−0.9) = 2 > +1) · step −1 → รีบตกกับดักให้จบ
  • โบนัส "เข้าใกล้" แต่ไม่หักเมื่อถอย → เดินเข้า-ออกเก็บโบนัส
  • ปลอดภัย: potential-based F = γΦ(s') − Φ(s) ไม่เปลี่ยน optimal policy
🕹️ 7. Deep RL และ Game Playing

CartPole (x, ẋ, θ, θ̇) ต่อเนื่อง → discretize 3×3×8×12 × 2 actions = 1,728 ค่า (เว็บแล็บ cartpole_web)

DQN: L(θ) = E(s,a,r,s')~D[ (r + γ maxₐ' Q(s',a'; θ⁻) − Q(s,a; θ))² ]
  • Replay buffer D สุ่ม mini-batch ลด correlation · Target net θ⁻ sync ทุก N steps ให้เป้านิ่ง
  • Atari: 84×84×4 (frame stacking) → Conv 32/8/4 → 64/4/2 → 64/3/1 → Dense 512 → Q ต่อ action
  • Policy gradient / REINFORCE: ปรับ πθ โดยตรง ∇J ≈ Σ Gₜ ∇log πθ(aₜ|sₜ)
ปีระบบแนวคิด

AIMA: minimax + alpha-beta ต้องรู้กฎและค้นต้นไม้เกม · AlphaZero = MCTS นำทางด้วย network ที่เรียนด้วย RL

⚠️ ข้อผิดพลาดที่พบบ่อย
  • ลืมกรณี terminated → บวก γ max Q(s') ทั้งที่เกมจบ
  • ใช้ np.argmax ตอน Q เป็น 0 ทั้งหมด → เลือก action 0 ซ้ำ (FrozenLake ไม่เคยถึง G)
  • ใช้ API เก่า import gym, step() คืน 4 ค่า · Gymnasium 1.x: FrameStack → FrameStackObservation
  • ประเมิน policy ด้วย ε > 0 หรือดูแค่ reward ระหว่างฝึก (ยังมีการสุ่มปนอยู่)
