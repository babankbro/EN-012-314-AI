🧭 1. ML อยู่ตรงไหน และ "เรียนรู้" คืออะไร

AI ⊃ Machine Learning ⊃ Deep Learning ⊃ LLM / GenAI — ML = ให้เครื่อง หากฎเองจากข้อมูล แทนมนุษย์เขียนกฎ

🧱 5. ความท้าทายหลัก

Bad data: ข้อมูลน้อย · ไม่เป็นตัวแทน (sampling bias) · คุณภาพต่ำ (noise, outlier, Glucose = 0) · feature ไม่เกี่ยวข้อง → feature engineering

อาการวิธีแก้
Underfiterror สูงทั้ง train และ valโมเดลซับซ้อนขึ้น, feature ดีขึ้น, ลด regularization
Overfittrain ดีมาก val แย่ (ช่องว่างกว้าง)ลดความซับซ้อน, regularization, เพิ่มข้อมูล, ลด noise
degree | train MSE | val MSE 1 | 0.185 | 0.231 # underfit 3 | 0.018 | 0.026 # พอดี 15 | 0.007 | 3.953 # overfit

Parameter = โมเดลเรียนเอง (θ) · Hyperparameter = กำหนดก่อนฝึก (degree, max_depth, k)

🧪 6. Train / Validation / Test และ Cross-Validation
Train 60% (ฝึก) · Validation 20% (เลือกโมเดล) · Test 20% (วัดครั้งเดียว)
X_temp, X_test, y_temp, y_test = train_test_split( X, y, test_size=0.2, stratify=y, random_state=42) scores = cross_val_score(model, X_temp, y_temp, cv=5) print(scores.mean(), scores.std()) # เฉลี่ย ± ความแกว่ง
CV score = (1/k) Σ scoreᵢ
  • Data snooping bias: ใช้ test set เลือกโมเดล → ผลดีเกินจริง
  • Data mismatch: val/test ต้องเป็นตัวแทนข้อมูลใช้งานจริง
  • No Free Lunch: ไม่มีโมเดลใดดีที่สุดทุกปัญหา ต้องลองและ validate
📜 7. ระบบฐานความรู้และกฎ (Knowledge-based)

Knowledge base (กฎ IF-THEN) + Working memory (ข้อเท็จจริง) + Inference engine + คำอธิบายเหตุผล

Modus Ponens: P ⇒ Q, P ⊢ Q  ·  P ⇒ Q เป็นเท็จเมื่อ P = T, Q = F เท่านั้น
Forwarddata-driven: ข้อเท็จจริง → ใช้กฎ → ข้อเท็จจริงใหม่ จนไม่มีอะไรเพิ่ม
Backwardgoal-driven: เริ่มจากเป้าหมาย ย้อนหาเงื่อนไข (Prolog)
for conditions, conclusion in rules: if conditions <= facts and conclusion not in facts: facts.add(conclusion); fired = True
