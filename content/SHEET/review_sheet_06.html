🔬 1. Artificial Neuron และ Perceptron
z = w₁x₁ + w₂x₂ + … + wₙxₙ + b = wᵀx + b  →  a = φ(z)
weight wความสำคัญของ input แต่ละตัว (synapse)
bias bเลื่อนจุดตัดสินใจ (เหมือนจุดตัดแกน)
activation φใส่ non-linearity ให้ output

Perceptron = TLU ใช้ step function · กฎการเรียนรู้ (ปรับเมื่อทำนายผิดเท่านั้น):

wᵢ ← wᵢ + η (y − ŷ) xᵢ    b ← b + η (y − ŷ)

XOR แบ่งด้วยเส้นตรงไม่ได้ (not linearly separable) → Perceptron ชั้นเดียวแก้ไม่ได้ → ต้องมี hidden layer (MLP)

🏗️ 2. MLP และการนับพารามิเตอร์

params ของ Dense = n_in × n_out + n_out = (n_in + 1) × n_out

🔁 5. Backpropagation และ Optimizers
  1. Forward pass คำนวณ output ทีละชั้น แล้ววัด loss
  2. Reverse pass หา ∂L/∂w ทุกตัวด้วย chain rule ย้อนจาก output
  3. Gradient descent step ปรับ weight
∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w    w ← w − η ∂L/∂w

sigmoid + BCE: ∂L/∂z = ŷ − y → ∂L/∂wᵢ = (ŷ − y)xᵢ · steps/epoch = ⌈N_train / batch_size⌉ (54,000/32 → 1,688)

Optimizerแนวคิด
SGDก้าวคงที่ตาม gradient
Momentum / NAGจำความเร็วเดิม (ลูกโบว์ลิ่ง) / มองไปข้างหน้า 1 ก้าว
AdaGradลด lr ในแกนชัน แต่มักหยุดเร็วเกินไป
RMSPropสนเฉพาะ gradient² ช่วงหลัง (moving average)
AdamMomentum + RMSProp · เริ่มที่ lr = 1e-3
🛠️ 6. ฝึก Deep Network ให้สำเร็จ

Vanishing / Exploding gradients: คูณอนุพันธ์หลายชั้น เช่น 0.25¹⁰ ≈ 9.5×10⁻⁷ → ชั้นล่างไม่เรียนรู้

InitializationGlorot σ² = 2/(fan_in+fan_out) (sigmoid/tanh) · He σ² = 2/fan_in (ReLU)
ActivationReLU, Leaky ReLU, ELU, SELU แทน sigmoid ใน hidden
BatchNormnormalize ต่อ mini-batch แล้ว scale/shift ด้วย γ, β
ClippingAdam(clipnorm=1.0) กัน exploding

ลด overfitting: EarlyStopping (patience, restore_best_weights) · Dropout (ปิด neuron แบบสุ่ม เฉพาะตอนฝึก) · ℓ1/ℓ2 · max-norm

💻 7. Keras Workflow (Colab: Runtime → T4 GPU)
import keras data = keras.datasets.fashion_mnist.load_data() (X_tr, y_tr), (X_te, y_te) = data X_tr, X_te = X_tr / 255.0, X_te / 255.0 model = keras.Sequential([ keras.Input(shape=(28, 28)), keras.layers.Flatten(), keras.layers.Dense(300, activation="relu"), keras.layers.Dropout(0.2), # ไม่บังคับ keras.layers.Dense(10, activation="softmax")]) model.compile(loss="sparse_categorical_crossentropy", optimizer="adam", metrics=["accuracy"]) es = keras.callbacks.EarlyStopping(patience=5, restore_best_weights=True) h = model.fit(X_tr, y_tr, epochs=30, validation_split=0.1, callbacks=[es]) model.evaluate(X_te, y_te) # MLP ≈ 0.87–0.89 model.predict(X_te[:3]).argmax(axis=1)

ไม่มี GPU: sklearn.neural_network.MLPClassifier(hidden_layer_sizes=(300, 100)) ได้ test acc ≈ 0.89

⚠️ ข้อผิดพลาดที่พบบ่อย
  • ลืม scale pixel (/255.0) → ฝึกช้าและ accuracy ต่ำ
  • ใช้ categorical_crossentropy กับ label จำนวนเต็ม (ต้อง one-hot) หรือกลับกัน
  • ใส่ softmax/sigmoid ที่ output ของ regression → ทำนายได้แค่ 0–1
  • นับพารามิเตอร์ลืม bias หรือไปนับ Flatten/Dropout
  • เลือกโมเดลจาก train accuracy แทน val_loss → overfit
  • learning rate ใหญ่เกิน → loss แกว่ง/กลายเป็น nan
