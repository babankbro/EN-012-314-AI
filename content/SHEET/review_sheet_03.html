🏷️ 1. Classification คืออะไร

ทำนายคำตอบที่เป็น หมวดหมู่ ("แบบไหน?") ต่างจาก Regression ที่ทำนายค่าต่อเนื่อง ("เท่าไหร่?") โมเดลลาก decision boundary แยกคลาส

Binary2 คลาส (positive = 1 คือ "สิ่งที่ตามหา" เช่น ป่วย, spam)
Multiclass> 2 คลาส อยู่ได้คลาสเดียว (MNIST 0–9) · กลยุทธ์ OvR / OvO (SVC ใช้ OvO)
Multilabel1 ตัวอย่างมีหลาย label พร้อมกัน

API เดียวกันทุกตัว: fit · predict · predict_proba · decision_function · score (= accuracy)

📈 2. Logistic Regression
z = θᵀx  →  p̂ = σ(z) = 1 / (1 + e−z)  ·  σ(0) = 0.5

ทาย 1 เมื่อ p̂ ≥ threshold (ค่าเริ่มต้น 0.5 ⇔ z ≥ 0) → เส้นแบ่งเป็นเส้นตรง · ฝึกด้วย log loss

Softmax: p̂ₖ = esₖ / Σⱼ esⱼ  (รวมทุกคลาส = 1)
from sklearn.linear_model import LogisticRegression clf = LogisticRegression(C=1.0, max_iter=1000).fit(X_train, y_train) proba = clf.predict_proba(X_test)[:, 1] # P(คลาส 1)

หลายคลาสใช้ softmax อัตโนมัติ — ห้ามใช้ multi_class=... (ถูกถอดแล้ว) · C เล็ก = regularize มาก

🧮 7. สูตร Metrics + ตัวอย่างคำนวณ
Accuracy = (TP + TN) / ทั้งหมด
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
Specificity = TN / (TN + FP)
F1 = 2PR / (P + R) = 2TP / (2TP + FP + FN)

ตัวอย่าง TN = 135, FP = 15, FN = 10, TP = 40 (n = 200)

  • Accuracy = 175/200 = 0.875 · Precision = 40/55 = 0.727
  • Recall = 40/50 = 0.800 · Specificity = 135/150 = 0.900 · F1 = 80/105 = 0.762

Precision = "ทายว่า positive แล้วถูกกี่ %" · Recall = "positive จริงหาเจอกี่ %" · F1 ใช้ค่าเฉลี่ยฮาร์มอนิก ลงโทษค่าที่ต่ำ

⚖️ 8. Imbalanced · Threshold · ROC

Accuracy หลอกได้! "ไม่ใช่เลข 5" ทุกภาพ → accuracy 0.910 แต่ recall = 0

proba = clf.predict_proba(X)[:, 1] y_pred = (proba >= 0.3).astype(int) # ลด threshold
ลด thresholdเพิ่ม threshold
Recall ↑ Precision ↓ (FN ลด FP เพิ่ม)Precision ↑ Recall ↓
คัดกรองโรค, จับการโกง (FN แพง)กรอง spam (FP แพง)
  • ROC: TPR (recall) vs FPR = FP/(FP+TN) · AUC 1.0 = สมบูรณ์, 0.5 = เดาสุ่ม · ไม่ขึ้นกับ threshold
  • macro avg = เฉลี่ยทุกคลาสเท่ากัน · weighted avg = ถ่วงด้วย support (ใกล้ accuracy) → macro ≪ weighted = คลาสส่วนน้อยแย่
⚠️ ข้อผิดพลาดที่พบบ่อย
  • ดูแค่ accuracy กับข้อมูลไม่สมดุล — ต้องดู confusion matrix, recall, F1 และเทียบ Dummy
  • สลับ FP/FN หรืออ่าน confusion matrix ผิดแกน (บางตำรา positive อยู่ก่อน)
  • ลืม scale ข้อมูลก่อน KNN/SVM · fit scaler กับข้อมูลทั้งหมด (leakage) → ใช้ Pipeline
  • เลือก threshold / k / C จาก test set → ต้องใช้ validation หรือ cross-validation
  • ใช้โค้ดเก่า np.int, multi_class= → เปลี่ยนเป็น int และไม่ต้องระบุ
  • สรุปว่าโมเดลใดดีกว่าจากความต่าง 0.01 บน test set เล็ก ๆ (114 ตัวอย่าง ≈ 1 ตัว)
