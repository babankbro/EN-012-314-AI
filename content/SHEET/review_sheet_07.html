  • Partial connectivity — neuron มองเฉพาะหน้าต่างเล็ก (receptive field) แนวคิดจาก visual cortex (Hubel & Wiesel)

  • เรียนรู้เป็นลำดับชั้น: ขอบ/เส้น → มุม/ลวดลาย → ชิ้นส่วนวัตถุ → คลาส
🔍 2. Convolution Layer
Z[i,j] = Σu Σv X[i·s+u, j·s+v] · K[u,v] + b

วาง filter บนภาพ → คูณทีละตัว → บวกรวม → ได้ 1 ค่าใน feature map (จริง ๆ คือ cross-correlation)

patch kernel (vertical edge) 3 0 1 1 0 -1 1 5 8 1 0 -1 2 7 2 1 0 -1 (3+1+2) − (1+8+2) = −5
filtersจำนวน filter = ความลึก output
kernel_sizeขนาดหน้าต่าง เช่น 3
stridesระยะเลื่อนต่อก้าว
paddingvalid ไม่เติม / same เติม 0 ให้ขนาดเท่าเดิม

filter มีความลึก = Cin เสมอ (ก้อน k×k×Cin) · ค่าใน filter เรียนรู้ด้วย backpropagation · ตามด้วย ReLU

🏗️ 5. สถาปัตยกรรม CNN

[Conv → ReLU → Pool] × n → Flatten/GAP → Dense → Softmax · ลึกขึ้น = เล็กลงแต่หนาขึ้น

model = keras.Sequential([ keras.Input(shape=(28, 28, 1)), layers.Conv2D(32, 3, activation="relu"), layers.MaxPooling2D(2), layers.Conv2D(64, 3, activation="relu"), layers.MaxPooling2D(2), layers.Flatten(), layers.Dropout(0.5), layers.Dense(10, activation="softmax")]) # 34,826 params

⚠️ ข้อผิดพลาดที่พบบ่อย
  • ลืมแกน channel/batch → ต้องเป็น (N, 28, 28, 1) แม้ทำนายภาพเดียว (1, 28, 28, 1)
  • ลืม Cin หรือ +1 (bias) ตอนคำนวณ params · ลืม +1 ในสูตรขนาด output
  • one-hot แต่ใช้ sparse_categorical_crossentropy (หรือกลับกัน) → shape error
  • ภาพจริงไม่ผ่าน pipeline เดียวกับตอนฝึก: ไม่ ÷255, ไม่กลับสี, ไม่จัดตัวเลขกลางภาพ
