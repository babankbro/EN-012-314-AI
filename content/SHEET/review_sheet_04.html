📈 1. Linear Regression & Cost Function

Regression = ทำนายตัวเลขต่อเนื่อง ("เท่าไหร่?") ต่างจาก Classification ที่ทำนายหมวดหมู่ ("แบบไหน?")

y = β₀ + β₁x + ε   |   ŷ = θ₀ + θ₁x₁ + … + θₙxₙ = θᵀx
β₀ / θ₀intercept (bias) — ค่า ŷ เมื่อทุก x = 0
β₁ / θᵢslope / weight — ŷ เปลี่ยนเท่าไรเมื่อ xᵢ +1 หน่วย (feature อื่นคงที่)
εerror term — ส่วนที่สมการอธิบายไม่ได้
MSE(θ) = (1/m) Σ (θᵀx⁽ⁱ⁾ − y⁽ⁱ⁾)² → หา θ ที่ทำให้ต่ำสุด (convex, ชามรูปเดียว)
⚙️ 2. Normal Equation vs Gradient Descent
θ̂ = (XᵀX)⁻¹ Xᵀy
θ ← θ − η · (2/m) Xᵀ(Xθ − y)
Normal EquationGradient Descent
รอบการคำนวณครั้งเดียวหลาย epoch, ต้องเลือก η
feature เยอะมากช้า O(n²·⁴–n³)ทำได้ดี
ต้อง scaleไม่จำเป็นจำเป็น
  • η เล็กไป → ลู่เข้าช้า · η พอดี → ถึงคำตอบเดียวกับ Normal Eq. · η ใหญ่ไป → แกว่ง/diverge (MSE ระเบิด)
  • Batch ใช้ข้อมูลทั้งหมด (นิ่ง ช้า) · SGD ทีละ 1 ตัวอย่าง (เร็ว แกว่ง) · Mini-batch กลุ่มเล็ก (ใช้ใน Deep Learning)
🧮 3. Polynomial & Regularization

PolynomialFeatures(degree=d) เติม x², x³… ให้เส้นโค้งได้ — degree สูง → overfitting

วิธีPenalty ที่บวกเข้า MSEผลต่อ θ
Ridge (L2)α Σ θᵢ²หดเข้าหา 0 แต่ไม่เป็น 0
Lasso (L1)α Σ |θᵢ|บางตัว = 0 พอดี → เลือก feature
Elastic Netrα Σ|θᵢ| + ((1−r)/2) α Σθᵢ²ผสม (r = l1_ratio)

α ใหญ่เกิน → underfit (California: Lasso(0.1) ตัด 5/8 feature, RMSE 0.746 → 0.824) · เลือก α ด้วย CV (RidgeCV, LassoCV) · ต้อง scale ก่อน

📏 4. SVR & Feature Scaling

SVR: ให้จุดอยู่ในท่อกว้าง ε รอบเส้นทำนาย — จุดในท่อไม่ถูกลงโทษ จุดนอกท่อ = support vectors · C มาก → ตามข้อมูลแน่น (เสี่ยง overfit) · kernel="rbf" จับความไม่เชิงเส้น · ฝึก O(m²–m³) → ข้อมูลใหญ่ใช้ LinearSVR หรือ subsample

Min-Max: x′ = (x − min)/(max − min) ∈ [0,1]
Standard: z = (x − μ)/σ
ต้อง scaleGD/SGD, Ridge/Lasso, SVR, KNN, Neural Net
ไม่จำเป็นLinearRegression (Normal Eq.), Decision Tree, Random Forest, Gradient Boosting
from sklearn.pipeline import make_pipeline svr = make_pipeline(StandardScaler(), SVR(kernel="rbf", C=10, epsilon=0.1)) svr.fit(X_train, y_train) # scaler fit เฉพาะ train → กัน leakage
🎯 5. Metrics สำหรับ Regression
Metricสูตรหน่วย / การตีความ
MAE(1/n) Σ |yᵢ − ŷᵢ|เท่ากับ y · พลาดเฉลี่ย ทน outlier
MSE(1/n) Σ (yᵢ − ŷᵢ)²y² · ใช้เป็น loss ตอนฝึก
RMSE√MSEเท่ากับ y · ไวต่อ error ใหญ่ (≥ MAE เสมอ)
R²1 − SS_res / SS_totสัดส่วนความแปรปรวนที่อธิบายได้ · 1 ดีสุด · ติดลบได้

ตัวอย่าง y = [20,25,30,35,40], ŷ = [22,24,33,33,38] → e = [−2,1,−3,2,2]

MAE = 10/5 = 2.0 · MSE = 22/5 = 4.4 · RMSE = √4.4 ≈ 2.098 · ȳ = 30, SS_tot = 250 → R² = 1 − 22/250 = 0.912

from sklearn.metrics import (mean_absolute_error, root_mean_squared_error, r2_score) rmse = root_mean_squared_error(y_test, y_pred) # sklearn ≥ 1.4 r2 = r2_score(y_test, y_pred) # squared=False ถูกถอดแล้ว

RMSE ≫ MAE → มีบางตัวอย่างพลาดหนัก · ตีความพร้อมหน่วยเสมอ · เทียบ baseline (ทายค่าเฉลี่ย → RMSE ≈ std ของ y)
