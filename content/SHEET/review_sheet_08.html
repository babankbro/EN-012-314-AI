รวบรวมข้อมูล+label → Cleaning → Tokenization → Stop words → Stem/Lemma → Feature (BoW/TF-IDF) → Model → Pos/Neg/Neutral

  • รวบรวมข้อมูล: label มาจากไหน (ติดเอง / ดาวรีวิว 4–5 = บวก) · สมดุลคลาส · ตรงโดเมนใช้งานจริง · ปิดบังข้อมูลส่วนบุคคล
  • ไม่จำเป็นต้องใช้ทุกขั้น — เลือกตามภาษาและงาน (sentiment ห้ามลบคำปฏิเสธ, ไทยแทบไม่ต้อง stem)

🔢 4. Features: BoW · TF-IDF · n-gram · Embedding

BoW = นับจำนวนครั้งของแต่ละคำ ไม่สนลำดับ → sparse matrix · ข้อจำกัด: คำทั่วไปได้ค่าสูง, มิติ = ขนาด vocabulary, ไม่รู้ว่า good ≈ great

tfidf(t,d) = tf(t,d) × idf(t)
sklearn: idf(t) = ln[(1+n) / (1+df(t))] + 1 → แล้ว L2-normalize แต่ละแถว

สูตรตำรา: idf = log(n/df) · คำที่อยู่ทุกเอกสารได้ idf = 1 (ต่ำสุด) ใน sklearn

ตัวอย่าง n = 3: d1 "good phone good price", d2 "bad phone", d3 "good camera"
คำdfidfd1: tf×idf → /‖·‖
good21.28772×1.2877=2.5754 → 0.7710
phone21.28771.2877 → 0.3855
price11.69311.6931 → 0.5069 (‖d1‖ = 3.3403)
TfidfVectorizer(ngram_range=(1, 2)) # unigram + bigram TfidfVectorizer(analyzer="char_wb", ngram_range=(2, 4)) # ไทย: ไม่ต้องตัดคำ TfidfVectorizer(tokenizer=thai_tokenize, token_pattern=None) # ไทย: ตัดคำด้วย newmm
  • n-gram: "not good" เป็น bigram → จับรูปปฏิเสธได้ แต่ฟีเจอร์เพิ่มเร็ว ("the food is not good" → 5 uni + 4 bi = 9)
  • Word2Vec: dense vector 1 คำ 1 เวกเตอร์ คำบริบทคล้ายกันอยู่ใกล้กัน · king − man + woman ≈ queen
  • Contextual (BERT, WangchanBERTa): เวกเตอร์เปลี่ยนตามประโยค ("ขันน้ำ" vs "ขันดี")
cos θ = (a · b) / (‖a‖ ‖b‖)

🤖 6. NLU: Intent + Fallback + Slot

ข้อความ → Preprocess → Intent classifier → ความมั่นใจ ≥ threshold? → ใช่: ดึง slot → ตอบ · ไม่: fallback ส่งแอดมิน

def understand(text, threshold=0.5): proba = intent_clf.predict_proba([text])[0] best = int(np.argmax(proba)) if proba[best] < threshold: return "ไม่เข้าใจ (ส่งต่อแอดมิน)", proba[best] return intent_clf.classes_[best], proba[best] re.search(r"(\d+)\s*(ชิ้น|ตัว|กล่อง)", text) # slot จำนวน re.search(r"[A-Z]{2}\d{8,12}", text) # เลขพัสดุ

ผลจริง (threshold 0.5): "ราคาเท่าไหร่คะ" → ถามราคา 0.92 · "วันนี้ฝนตกไหม" → ไม่เข้าใจ 0.44

  • Intent = ผู้ใช้ต้องการอะไร (ถามราคา / สั่งซื้อ / ติดตามพัสดุ / ร้องเรียน)
  • Slot/Entity = รายละเอียด (จำนวน, สี, เลขพัสดุ) — regex หรือ NER · ขาด slot → ถามกลับ
  • threshold สูง → fallback บ่อย · ต่ำ → ตอบผิดเมื่อคำถามนอกขอบเขต — เลือกจาก validation

⚠️ ข้อผิดพลาดที่พบบ่อย
  • ลบ stop words มาตรฐานในงาน sentiment → "not", "ไม่", "แต่" หาย ความหมายกลับขั้ว
  • ใช้ fit_transform กับ test set → vocabulary ใหม่/รั่ว ต้องใช้ transform หรือ Pipeline
  • ลบ emoji/":)"/"555" ทิ้งทั้งที่เป็นสัญญาณอารมณ์ → ควรแปลงเป็นคำแทน
  • ลืม keep_whitespace=False → ช่องว่างกลายเป็น token
  • สับสนสูตร idf: sklearn = ln((1+n)/(1+df)) + 1 และ normalize L2 ไม่ใช่ log(n/df)
  • chatbot ไม่มี fallback → เดา intent ผิดกับคำถามนอกขอบเขต
  • ข้อมูลแชตลูกค้ามีข้อมูลส่วนบุคคล (PDPA) และอคติ (ภาษาถิ่น เพศ) — ปิดบังและตรวจก่อนฝึก
