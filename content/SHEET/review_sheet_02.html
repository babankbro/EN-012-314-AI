IQR = Q₃ − Q₁  ·  outlier ถ้า x < Q₁ − 1.5·IQR หรือ x > Q₃ + 1.5·IQR

ตัวอย่าง Age: Q₁=24, Q₃=41 → IQR=17 → ขอบบน 66.5 ปี · outlier ทางการแพทย์อาจเป็นค่าจริง อย่าลบอัตโนมัติ (ใช้ capping/log/tree-based แทนได้)

🚰 5. Data Leakage — fit กับ train เท่านั้น

Data leakage = ข้อมูลจาก test (หรือข้อมูลที่ไม่มีตอนใช้งานจริง) รั่วเข้าสู่การฝึก → ผลประเมินดีเกินจริง

# ผิด: เรียน μ, σ จากข้อมูลทั้งหมดก่อนแบ่ง X_s = StandardScaler().fit_transform(X); train_test_split(X_s, y) # ถูก: แบ่งก่อน แล้ว fit กับ train X_train_s = scaler.fit_transform(X_train) X_test_s = scaler.transform(X_test) # ห้าม fit!

fittrainเรียน median, μ, σ, min, max, คะแนน feature
transformtrain, test, ข้อมูลใหม่แปลงด้วยค่าที่เรียนไว้
fit_transformtrainfit + transform

หลัง scale: mean ของ train = 0 พอดี แต่ test ≠ 0 (เช่น 0.04, 0.19) — ถูกต้อง เพราะจำลองข้อมูลใหม่ในโลกจริง · leakage เกิดได้กับ imputer, SelectKBest, encoder และ feature ที่ "รู้ผลล่วงหน้า" ด้วย

📏 7. Feature Scaling
Standard: z = (x − μ) / σ
MinMax: x′ = (x − min)/(max − min)

Glucose ชุดเล็ก: μ=127.07, σ=28.26, min=90, max=180 → x=105: z ≈ −0.781, x′ = 15/90 ≈ 0.167 · StandardScaler ใช้ σ แบบ ddof=0

⚠️ ข้อผิดพลาดที่พบบ่อย
  • Data leakage: fit_transform(X) ทั้งชุดก่อน split · fit กับ test → ใช้ transform เท่านั้น
  • เชื่อ isna() อย่างเดียว ไม่ดู describe() → พลาดค่าว่างแฝง (0, −1, 999)
  • เลือก feature จากข้อมูลดิบ/ทั้งชุด → corr ถูกบิดเบือน และ leak
  • ลืม stratify เมื่อคลาสไม่สมดุล · ลืม random_state
  • ดูแค่ accuracy โดยไม่เทียบ dummy baseline · ใช้ test set เลือกโมเดล
  • แทนหมวดหมู่ไม่มีลำดับเป็น 0,1,2 แทน one-hot
