🧠 4. ML และ Neural Network (ระดับ 2–3)

ML: ข้อมูล + คำตอบตัวอย่าง → อัลกอริทึม → โมเดล · Classification/Clustering, Decision Tree, SVM, Regression, Unsupervised, Dimensionality Reduction, Semi-supervised, RL

นิวรอน: z = w₁x₁ + … + wₙxₙ + b  →  a = f(z)
Activationช่วงค่าใช้ที่
Sigmoid0 ถึง 1output แบบ binary
Tanh−1 ถึง 1สถานะใน LSTM
ReLUmax(0, z)ชั้นซ่อน (deep CNN)
Softmaxรวมกัน = 1output หลายคลาส
Linearไม่จำกัดoutput ของ regression

Backprop: forward pass → loss → backward pass (gradient) → optimizer (SGD, Adam) ปรับ w · MLP มีชั้นซ่อนจึงแก้ XOR ได้ · CNN, LSTM, SOM ก็เป็น NN

🤖 5. AI Agent
Sensors → percept → Reasoning/Planning (+Memory) → Actuators/Tools → action

PEAS: Performance · Environment · Actuators · Sensors — สภาพแวดล้อม: fully/partially observable, deterministic/stochastic, episodic/sequential, static/dynamic, single/multi-agent

ประเภท: Simple reflex (percept ปัจจุบัน) → Model-based (จำสถานะ) → Goal-based → Utility-based → Learning agent · Multi-agent

LLM agent: คิด → เรียก tool (function calling) → ดูผล วนจนเสร็จ (ReAct) — จำกัดสิทธิ์ + ให้คนยืนยันการกระทำที่ย้อนไม่ได้

🧬 6. สถาปัตยกรรม Deep Learning
โมเดลแนวคิดใช้กับ
CNNfilter + pooling สกัด feature ภาพจำแนกภาพ
RNN/LSTMhidden state + gate จำลำดับอนุกรมเวลา
Autoencoderบีบเป็นรหัสสั้น แล้วสร้างคืนลดมิติ, denoise
Transferpre-trained → fine-tune งานใหม่ข้อมูลน้อย

GAN (Goodfellow 2014): Generator z (latent) → ภาพปลอม พยายามหลอก · Discriminator แยกจริง/ปลอม · ฝึกสลับกัน → สมดุล D ≈ 0.5 · ใช้แค่ G สร้าง · ปัญหา: ฝึกไม่เสถียร, mode collapse

⚡ 7. Transformer (2017) → LLM → ChatGPT
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) · V

Self-Attention มองทุก token พร้อมกัน หาบริบท (แต่ละแถว softmax รวม = 1) · Positional Encoding บอกลำดับคำ · Encoder เข้าใจ input · Decoder สร้างทีละ token (masked)

Encoder-onlyDecoder-onlyEnc–Dec
BERT: เข้าใจ/จำแนกGPT, Llama: สร้างข้อความT5: แปล สรุป

LLM: Pre-training (ทายคำถัดไป) → SFT → RLHF → Chat model · token, prompt, temperature, context window

✨ 8. Generative AI และ Responsible AI
DiscriminativeGenerative
เรียนP(y | x) ขอบเขตแยกคลาสP(x) การกระจายของข้อมูล
ตัวอย่าง"ภาพนี้คือแมวไหม""สร้างภาพแมว" (ข้อความ ภาพ เสียง โค้ด)

Hallucination = ฟังน่าเชื่อแต่ผิด เพราะเลือก token ที่ น่าจะเป็น ไม่ใช่ จริง → ลดด้วย RAG, อ้างแหล่งที่มา, ใช้ tool, คนตรวจ

Responsible AI: bias (ตรวจผลแยกกลุ่ม) · privacy (ไม่ป้อนข้อมูลส่วนบุคคล, PDPA) · deepfake/ลิขสิทธิ์ · accountability (human-in-the-loop)
