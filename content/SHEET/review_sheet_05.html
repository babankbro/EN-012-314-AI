🎯 1. K-Means
  1. Scale ข้อมูล → กำหนด k → วาง centroid เริ่มต้น (k-means++)
  2. Assignment: จัดแต่ละจุดเข้า centroid ที่ใกล้ที่สุด (Euclidean)
  3. Update: ย้าย centroid ไปที่ ค่าเฉลี่ย ของสมาชิก
  4. วนข้อ 2–3 จน centroid ไม่ขยับ (inertia ลดลงหรือเท่าเดิมทุกรอบ)
inertia = Σᵢ ‖ x⁽ⁱ⁾ − μc(i) ‖²
from sklearn.cluster import KMeans km = KMeans(n_clusters=4, n_init=10, random_state=42) labels = km.fit_predict(X_scaled) km.cluster_centers_, km.inertia_ # centroid, inertia km.predict(X_new) # จัดกลุ่มข้อมูลใหม่ได้

ตัวอย่างมือ: A(1,1) B(2,1) C(4,3) D(5,4) E(1,2) F(4,4), init = A, B → รอบ 2 B ย้ายกลุ่ม → ลู่เข้ารอบ 3 μ = (1.33,1.33), (4.33,3.67), inertia = 2.667

📏 2. เลือก k: Elbow & Silhouette

Elbow: plot inertia vs k หา "ข้อศอก" — ห้ามเลือก inertia ต่ำสุด เพราะลดลงเสมอเมื่อ k เพิ่ม

s(i) = (b − a) / max(a, b)  ∈ [−1, 1]
aระยะเฉลี่ยถึงจุดอื่นใน กลุ่มเดียวกัน
bระยะเฉลี่ยถึงจุดใน กลุ่มที่ใกล้ที่สุดถัดไป
แปลผล≈ +1 ถูกกลุ่ม · ≈ 0 อยู่ขอบ · < 0 น่าจะผิดกลุ่ม → เลือก k ที่ silhouette เฉลี่ยสูงสุด
from sklearn.metrics import silhouette_score for k in range(2, 9): km = KMeans(n_clusters=k, n_init=10).fit(X) print(k, km.inertia_, silhouette_score(X, km.labels_))

ตัวอย่าง make_blobs 4 กลุ่ม: inertia 15386 → 3125 → 607 → 548 และ silhouette สูงสุด 0.834 ที่ k = 4

⚖️ 3. Feature Scaling กับระยะทาง

feature หน่วยใหญ่ (รายได้ หลักหมื่น) ครอบงำ ระยะ Euclidean ของ feature หน่วยเล็ก (อายุ) → ต้อง scale ก่อน K-Means / DBSCAN / KNN / PCA

from sklearn.pipeline import make_pipeline model = make_pipeline(StandardScaler(), KMeans(3, n_init=10))

ลูกค้า 3 กลุ่ม (อายุ, รายได้): ARI ไม่ scale = 0.501 → scale แล้ว = 1.0

ARI (Adjusted Rand Index): 1 = ตรงเฉลยทั้งหมด, ≈ 0 = เหมือนสุ่ม — ใช้ได้เมื่อมีเฉลยให้ตรวจเท่านั้น

🌙 4. DBSCAN (density-based)
Coreมีเพื่อนบ้านในรัศมี eps ≥ min_samples จุด (นับตัวเอง)
Borderไม่ใช่ core แต่อยู่ในรัศมีของ core → เข้ากลุ่มนั้น
Noiseไม่ใช่ทั้งสองแบบ → label -1
db = DBSCAN(eps=0.2, min_samples=5).fit(X) db.labels_, db.core_sample_indices_ # ไม่มี predict()

make_moons: K-Means ARI 0.239 vs DBSCAN 1.0 · eps 0.05 → 7 กลุ่ม + noise 77 · eps 0.5 → รวมเป็น 1 กลุ่ม

K-Means เหมาะกับกลุ่มทรงกลมขนาดใกล้กัน (ขอบเขตเป็นเส้นตรง) · DBSCAN ข้อดี: ไม่ต้องกำหนด k, จับรูปร่างแปลกได้, แยก noise · ข้อเสีย: ไวต่อ eps, แย่เมื่อความหนาแน่นต่างกันมาก

📉 5. Dimensionality Reduction: PCA & t-SNE

Curse of dimensionality: มิติสูง → ข้อมูลกระจัดกระจาย ระยะใกล้/ไกลพอ ๆ กัน (d = 1000: min/max = 0.85) → overfit ง่าย

PCA (projection): PC1 = ทิศ variance สูงสุด, PC ถัดไปตั้งฉากกัน · center ให้อัตโนมัติ แต่ไม่ scale ให้

pca = PCA(n_components=0.95) # เก็บ variance 95% X_low = pca.fit_transform(X) pca.explained_variance_ratio_ # สัดส่วน variance ต่อ PC X_rec = pca.inverse_transform(X_low) # reconstruction

MNIST 10k ภาพ: 784 → 151 มิติ ได้ 95% · 2D เก็บได้แค่ 17.1% · digits: 64 → 29 มิติ

PCAt-SNE
แนวคิดLinear, รักษา varianceNon-linear, รักษา local structure
ใช้ทำpreprocessing, บีบอัดvisualization เท่านั้น
transform ข้อมูลใหม่✔ (+ inverse)✘ มีแค่ fit_transform

กฎเหล็ก: PCA → 30–50D ก่อน (ตัด noise, เร่งความเร็ว) แล้วจึง t-SNE → 2D · Manifold learning อื่น: LLE (คลี่ Swiss roll)

🚨 7. Anomaly Detection

GMM: ส่วนผสมของ Gaussian (วงรี ขนาด/ทิศต่างกันได้) ฝึกด้วย EM (E: ความน่าจะเป็น, M: ปรับ mean/cov/weight)

gm = GaussianMixture(n_components=3, n_init=10).fit(X) dens = gm.score_samples(X) # log-density ต่ำ = แปลก anom = dens < np.percentile(dens, 4) # ตัด 4% ล่างสุด iso = IsolationForest(contamination=0.04).fit(X) iso.predict(X) # -1 = ผิดปกติ

Isolation Forest: จุดโดดเดี่ยวถูกแยกได้ด้วยการตัดแบบสุ่มไม่กี่ครั้ง · threshold สูงขึ้น → recall ↑ precision ↓

⚠️ ข้อผิดพลาดที่พบบ่อย
  • ลืม scale ก่อน K-Means/DBSCAN/PCA → feature หน่วยใหญ่ครอบงำ (silhouette ของข้อมูลดิบชี้ k ผิดได้)
  • เลือก k จาก inertia ต่ำสุด · ไม่กำหนด n_init/random_state → ผลไม่คงที่
  • ใช้ K-Means กับกลุ่มรูปโค้ง/ความหนาแน่นต่างกัน · ตีความเลขกลุ่มว่าเป็น "label" จริง
  • ใช้ t-SNE ใน pipeline ทำนาย หรืออ่านระยะ/ขนาดกลุ่มบนกราฟ t-SNE เชิงปริมาณ
  • ลดมิติ PCA เหลือ 2D แล้วหวังให้ reconstruction คมชัด (2D เก็บ variance MNIST แค่ 17%)
