หน้านี้รวม**โจทย์คำนวณแนวข้อสอบกลางภาค**ทุกข้อ เรียงตามเลขข้อ 6–14 ข้อย่อยที่มี **(ก)** และ **(ข)** เป็นโจทย์แนวเดียวกันแต่ตัวเลขหรือสถานการณ์ต่างกัน แต่ละข้อมีโจทย์ ภาพอธิบายแนวคิด วิธีคำนวณทีละขั้น และคำตอบ ถ้าต้องการคำอธิบายเพิ่ม ให้ไปที่บทเรียนที่ระบุไว้ท้ายข้อ

> [!TIP]
> **วิธีใช้หน้านี้ให้ได้ผล:** อ่านโจทย์แล้วลองทำบนกระดาษพร้อมเครื่องคิดเลขก่อน จากนั้นจึงเปิดเฉลย ในห้องสอบให้เขียน **สูตร → แทนค่า → ผลลัพธ์** ทุกข้อ และตอบทศนิยมตามที่โจทย์กำหนด

### 6 (ก) ระบบกรองอีเมลขยะ

ทดสอบระบบกรองอีเมลขยะ (Spam Filter) กับอีเมล 400 ฉบับ พบว่าเป็นอีเมลขยะจริง 80 ฉบับ ซึ่งระบบตรวจจับได้ถูกต้อง 68 ฉบับ และจากอีเมลปกติ 320 ฉบับ ระบบระบุผิดว่าเป็นอีเมลขยะ 16 ฉบับ จงเติมเมทริกซ์ความสับสนและคำนวณ Accuracy, Precision, Recall, F1 และ Specificity (ทศนิยม 4 ตำแหน่ง)

![การแยกอีเมล 400 ฉบับเป็น TP, FN, FP, TN: ค่าที่โจทย์ไม่ได้ให้หาได้จากผลรวมของแต่ละแถว](/images/calc/q6-spam-tree.svg)

<details><summary>วิธีทำและคำตอบ</summary>

**ขั้นที่ 1 เติมตาราง** (คลาสบวก = อีเมลขยะ เพราะเป็นสิ่งที่ระบบต้องตรวจจับ)

| | ทำนายว่าเป็นอีเมลขยะ | ทำนายว่าเป็นอีเมลปกติ |
|---|---|---|
| **อีเมลขยะจริง (80)** | TP = 68 | FN = 80 − 68 = 12 |
| **อีเมลปกติจริง (320)** | FP = 16 | TN = 320 − 16 = 304 |

**ขั้นที่ 2 คำนวณ**

$$ \text{Accuracy} = \frac{TP + TN}{N} = \frac{68 + 304}{400} = 0.9300 $$

$$ \text{Precision} = \frac{TP}{TP + FP} = \frac{68}{84} = 0.8095 \qquad \text{Recall} = \frac{TP}{TP + FN} = \frac{68}{80} = 0.8500 $$

$$ F_1 = \frac{2TP}{2TP + FP + FN} = \frac{136}{164} = 0.8293 \qquad \text{Specificity} = \frac{TN}{TN + FP} = \frac{304}{320} = 0.9500 $$

**แปลความ:** อีเมลปกติ 95% เข้ากล่องจดหมายได้ถูกต้อง มีเพียง 5% ที่ถูกกรองทิ้งผิด

</details>

### 6 (ข) แบบจำลองคัดกรองโรคเบาหวาน

| | ทำนายว่าเป็นบวก | ทำนายว่าเป็นลบ |
|---|---|---|
| **ค่าจริงเป็นบวก** | TP = 52 | FN = 8 |
| **ค่าจริงเป็นลบ** | FP = 18 | TN = 122 |

จงคำนวณ Accuracy, Precision, Recall, F1 และ Specificity พร้อมแปลความหมาย (ทศนิยม 4 ตำแหน่ง)

<details><summary>วิธีทำและคำตอบ</summary>

ผลรวม = 52 + 8 + 18 + 122 = 200 (ป่วยจริง 60 คน ปกติจริง 140 คน)

$$ \text{Accuracy} = \frac{52 + 122}{200} = 0.8700 \qquad \text{Precision} = \frac{52}{52 + 18} = 0.7429 \qquad \text{Recall} = \frac{52}{52 + 8} = 0.8667 $$

$$ F_1 = \frac{2(52)}{2(52) + 18 + 8} = \frac{104}{130} = 0.8000 \qquad \text{Specificity} = \frac{122}{122 + 18} = 0.8714 $$

**แปลความ:** ผู้ที่ไม่ป่วยจริง 87.14% ถูกทำนายว่าปกติได้ถูกต้อง

</details>

> [!WARNING]
> จำให้แม่น: Precision หารด้วย**คอลัมน์**ที่ทำนายว่าเป็นบวก (TP + FP) ส่วน Recall หารด้วย**แถว**ที่เป็นบวกจริง (TP + FN) · เรียนเพิ่ม [บทที่ 3 หัวข้อ 7 และ 10](/module/03)

## ข้อ 7 การถดถอยเชิงเส้นและการถดถอยโลจิสติก

### 7.1 การทำนายด้วยสมการเชิงเส้น

**(ก)** แบบจำลองถดถอยเชิงเส้นพหุคูณ $\hat{y} = 10 + 2.5x_1 - 1.5x_2$ ทำนายค่าเมื่อ $x_1 = 4$ และ $x_2 = 2$ ได้เท่าใด และ $\theta_2 = -1.5$ มีความหมายอย่างไร

**(ข)** แบบจำลอง $\hat{y} = 5 + 2x$ ทำนายค่าเมื่อ $x = 3$ ได้เท่าใด และ $\theta_0, \theta_1$ หมายถึงอะไร

![ซ้าย: ŷ = 5 + 2x ที่ x = 3 ได้ 11 · ขวา: ผลรวมทีละพจน์ของแบบจำลองพหุคูณ 10 + 10 − 3 = 17](/images/calc/q7-linear-prediction.svg)

<details><summary>วิธีทำและคำตอบ</summary>

**(ก)** $\hat{y} = 10 + 2.5(4) - 1.5(2) = 10 + 10 - 3 = 17$ · $\theta_2 = -1.5$ หมายถึงเมื่อ $x_2$ เพิ่ม 1 หน่วยโดย $x_1$ คงที่ ค่าทำนายลดลง 1.5

**(ข)** $\hat{y} = 5 + 2(3) = 11$ · $\theta_0 = 5$ คือจุดตัดแกน (ค่าทำนายเมื่อ $x = 0$) และ $\theta_1 = 2$ คือความชัน ($x$ เพิ่ม 1 หน่วย ค่าทำนายเพิ่ม 2)

</details>

### 7.2 ค่าคลาดเคลื่อน MAE, MSE และ RMSE

**(ก)** ค่าจริง $y = [10, 12, 15, 20]$ ค่าทำนาย $\hat{y} = [11, 12, 13, 22]$ จงคำนวณ MAE และ RMSE และบอกว่าค่าใดไวต่อค่าคลาดเคลื่อนขนาดใหญ่มากกว่า

**(ข)** ค่าจริง $y = [4, 6, 8]$ ค่าทำนาย $\hat{y} = [3, 6, 11]$ จงคำนวณ MSE และ RMSE

![ซ้าย: พื้นที่สี่เหลี่ยมแทน e² ของแต่ละจุด · ขวา: e² ขยายค่าคลาดเคลื่อนขนาดใหญ่มากกว่า |e|](/images/calc/q7-error-metrics.svg)

<details><summary>วิธีทำและคำตอบ</summary>

**(ก)** $e = y - \hat{y} = (-1, 0, 2, -2)$

$$ MAE = \frac{1 + 0 + 2 + 2}{4} = 1.25 \qquad MSE = \frac{1 + 0 + 4 + 4}{4} = 2.25 \qquad RMSE = \sqrt{2.25} = 1.5 $$

RMSE ไวต่อค่าคลาดเคลื่อนขนาดใหญ่มากกว่า เพราะยกกำลังสองก่อนเฉลี่ย

**(ข)** $e = (1, 0, -3)$ → $e^2 = (1, 0, 9)$

$$ MSE = \frac{10}{3} = 3.3333 \qquad RMSE = \sqrt{3.3333} = 1.8257 $$

</details>

### 7.4 ฟังก์ชันซิกมอยด์และการถดถอยโลจิสติก

**(ก)** แบบจำลองทำนายความเสี่ยงเบาหวานจากระดับน้ำตาล $x$ ด้วย $z = -4 + 0.05x$ และ $\sigma(z) = \dfrac{1}{1 + e^{-z}}$ จงหาความน่าจะเป็นเมื่อ $x = 100$ คลาสที่ทำนาย (threshold 0.5) และค่า $x$ ที่ทำให้ความน่าจะเป็นเท่ากับ 0.5

**(ข)** จงคำนวณ $\sigma(z)$ เมื่อ $z = 1$ และ $z = -2$ และอธิบายว่าการถดถอยโลจิสติกใช้ค่านี้อย่างไร

![เส้นโค้งซิกมอยด์: z > 0 ให้ความน่าจะเป็นมากกว่า 0.5 และแกนบนแปลง z เป็นระดับน้ำตาลของโจทย์ (ก)](/images/calc/q7-sigmoid.svg)

<details><summary>วิธีทำและคำตอบ</summary>

**(ก)** $z = -4 + 0.05(100) = 1$ → $\sigma(1) = \dfrac{1}{1 + e^{-1}} = \dfrac{1}{1.3679} = 0.7311 \ge 0.5$ → **คลาส 1** · ความน่าจะเป็น = 0.5 เมื่อ $z = 0$ → $-4 + 0.05x = 0$ → $x = 80$

**(ข)** $\sigma(1) = 0.7311$ และ $\sigma(-2) = \dfrac{1}{1 + e^{2}} = \dfrac{1}{8.3891} = 0.1192$ · การถดถอยโลจิสติกนำ $z = \theta^T x$ ผ่าน sigmoid ได้ความน่าจะเป็นของคลาส 1 ถ้า $\ge 0.5$ ทายคลาส 1

</details>

## ข้อ 8 ต้นไม้ตัดสินใจและการเรียนรู้แบบรวมกลุ่ม

### 8.1 Gini Impurity

**(ก)** โหนดแม่มีคลาส A 5 ตัว และคลาส B 5 ตัว ถูกแบ่งเป็นโหนดซ้าย (A 4, B 1) และโหนดขวา (A 1, B 4) จงคำนวณ Gini ของโหนดแม่ และ Gini เฉลี่ยถ่วงน้ำหนักหลังแบ่ง

**(ข)** โหนดหนึ่งมีคลาส A 6 ตัว และคลาส B 4 ตัว จงคำนวณ Gini Impurity $= 1 - \sum p_i^2$

![ซ้าย: การแบ่งโหนดทำให้ Gini ลดจาก 0.50 เหลือ 0.32 · ขวา: โหนด A6 B4 มี Gini 0.48](/images/calc/q8-gini.svg)

<details><summary>วิธีทำและคำตอบ</summary>

**(ก)** แม่: $1 - (0.5^2 + 0.5^2) = 0.5$ · ซ้าย: $1 - (0.8^2 + 0.2^2) = 0.32$ · ขวา: $1 - (0.2^2 + 0.8^2) = 0.32$

$$ G_{\text{split}} = \tfrac{5}{10}(0.32) + \tfrac{5}{10}(0.32) = 0.32 \quad (\text{ลดลง } 0.18) $$

**(ข)** $1 - (0.6^2 + 0.4^2) = 1 - 0.52 = 0.48$

</details>

### 8.2 Hard Voting และ Soft Voting

**(ก)** แบบจำลอง 5 ตัวให้ความน่าจะเป็นของคลาส 1 เป็น 0.8, 0.45, 0.45, 0.45 และ 0.9

**(ข)** แบบจำลอง 3 ตัวให้ความน่าจะเป็นของคลาส 1 เป็น 0.2, 0.6 และ 0.6

![แท่งสีฟ้าโหวตคลาส 1 แท่งสีส้มโหวตคลาส 0 เส้นสีม่วงคือค่าเฉลี่ยที่ soft voting ใช้ตัดสิน](/images/calc/q8-voting.svg)

<details><summary>วิธีทำและคำตอบ</summary>

**(ก)** Hard: แปลงเป็นคลาส (1, 0, 0, 0, 1) → คลาส 0 ชนะ 3 : 2 → **คลาส 0** · Soft: $(0.8 + 0.45 \times 3 + 0.9)/5 = 0.61 \ge 0.5$ → **คลาส 1** (ต่างกันเพราะ soft voting นับความมั่นใจ)

**(ข)** Hard: (0, 1, 1) → **คลาส 1** · Soft: $(0.2 + 0.6 + 0.6)/3 = 0.4667 < 0.5$ → **คลาส 0**

</details>

## ข้อ 12 Q-Learning

### 12.1 ปรับค่า Q หนึ่งครั้ง

สมการ $Q(s,a) \leftarrow Q(s,a) + \alpha\big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]$

**(ก)** เอเจนต์ถึงเป้าหมายซึ่งเป็นสถานะสุดท้าย (จบตอน) ได้รางวัล $r = 10$ โดย $Q(s,a) = 4$, $\alpha = 0.5$, $\gamma = 0.9$ จงคำนวณ TD target, TD error และ $Q(s,a)$ ใหม่ พร้อมอธิบายว่าเหตุใดจึงไม่บวกพจน์ $\gamma \max_{a'} Q(s',a')$

**(ข)** $Q(s,a) = 3$, $\alpha = 0.2$, $r = 2$, $\gamma = 0.8$ และ $\max_{a'} Q(s',a') = 6$

![Q เดิมขยับเข้าหา TD target เป็นสัดส่วน α ของระยะห่าง](/images/calc/q12-q-update.svg)

<details><summary>วิธีทำและคำตอบ</summary>

**(ก)** จบตอนแล้วไม่มีสถานะถัดไป ผลตอบแทนในอนาคต = 0 → TD target = $r = 10$ · TD error = $10 - 4 = 6$ · $Q_{\text{ใหม่}} = 4 + 0.5(6) = 7$

**(ข)** TD target = $2 + 0.8(6) = 6.8$ · TD error = $6.8 - 3 = 3.8$ · $Q_{\text{ใหม่}} = 3 + 0.2(3.8) = 3.76$

</details>

### 12.2 ผลตอบแทนแบบมีส่วนลด

**(ก)** เอเจนต์ได้รางวัลตามลำดับ 0, 0, 0, 10 จงคำนวณ $G_0$ เมื่อ $\gamma = 0.9$

**(ข)** ถ้าได้รางวัล +1 ทุกก้าว ค่า Q จะเข้าใกล้ $\dfrac{1}{1 - \gamma}$ จงคำนวณเมื่อ $\gamma = 0.95$

![ซ้าย: น้ำหนัก γ^t ของแต่ละก้าว · ขวา: ผลตอบแทนสะสมลู่เข้า 1/(1−γ)](/images/calc/q12-discount.svg)

<details><summary>วิธีทำและคำตอบ</summary>

**(ก)** $G_0 = 0 + 0.9(0) + 0.9^2(0) + 0.9^3(10) = 0.729 \times 10 = 7.29$

**(ข)** $\dfrac{1}{1 - 0.95} = \dfrac{1}{0.05} = 20$

## ข้อ 14 หน่วยความจำของแบบจำลองภาษา (VRAM)

**(ก)** GPU มี VRAM 24 GB จะเก็บค่าน้ำหนักของแบบจำลองภาษาได้ใหญ่ที่สุดกี่พันล้านพารามิเตอร์ เมื่อเก็บแบบ 16 บิต และแบบ 4 บิต

**(ข)** แบบจำลองภาษาขนาด 13B ใช้ VRAM สำหรับเก็บค่าน้ำหนักเท่าใด เมื่อเก็บแบบ 16 บิต และแบบ 4 บิต

![ซ้าย: หน่วยความจำของโมเดล 13B ตามจำนวนบิต เทียบกับ GPU 24 GB · ขวา: ขนาดโมเดลสูงสุดที่ GPU 24 GB เก็บได้](/images/calc/q14-vram.svg)

<details><summary>วิธีทำและคำตอบ</summary>

หน่วยความจำ = จำนวนพารามิเตอร์ × (บิต ÷ 8) ไบต์ · 16 บิต = 2 ไบต์ · 4 บิต = 0.5 ไบต์

**(ก)** 16 บิต: 24 GB ÷ 2 = **12B** · 4 บิต: 24 GB ÷ 0.5 = **48B**

**(ข)** 16 บิต: 13 × 10⁹ × 2 = **26 GB** · 4 บิต: 13 × 10⁹ × 0.5 = **6.5 GB**

ตัวเลขนี้เป็นเฉพาะค่าน้ำหนัก การใช้งานจริงต้องเผื่อ KV cache และ overhead เพิ่ม

</details>
